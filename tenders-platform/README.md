# Нови поръчки — обществените поръчки в България, всяка сутрин

Всички нови обществени поръчки от отворените данни на ЦАИС ЕОП, с
търсене по бранш, област и бюджет, известия по имейл и платен достъп за
AI агенти по протокола x402.

- За собственика: [`docs/РЪЧНИ-СТЪПКИ.md`](docs/РЪЧНИ-СТЪПКИ.md)
- За програмисти: [`CLAUDE.md`](CLAUDE.md)

> Тази папка е отделен проект в общото repo `Trading-`, до
> `property-platform/` (imotpoint) и трейдинг демото в корена.

## Бърз старт без база данни

```bash
cd tenders-platform
npm install
npm run import -- 2026-09-28 2026-10-03   # пълни data/db.json с истински поръчки
npm run dev                               # http://localhost:3000
```

## Стек

| Слой | Избор |
|---|---|
| Сайт | Next.js 16, TypeScript, Tailwind CSS 4 |
| База | Supabase (Postgres), или JSON файл локално |
| Имейли | Resend |
| Плащания от ботове | x402 (USDC по мрежата Base) |
| Хостинг и дневни задачи | Vercel + Vercel Cron |
