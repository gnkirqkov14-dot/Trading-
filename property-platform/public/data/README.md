# Геоданни

`bulgaria-provinces.geojson` — граници на 28-те български области (admin-1),
извлечени и филтрирани от [Natural Earth](https://www.naturalearthdata.com/)
(`ne_10m_admin_1_states_provinces`, public domain — "no restrictions on use").
Cyrillic имената идват от полето `name_local` на оригиналния dataset.
