# Формат на учебното съдържание

Всеки файл `lessons-N.js` експортира масив от уроци:

```js
export default [
  {
    id: 1,                       // пореден номер на урока (уникален)
    title: "Здравей!",           // заглавие на български, кратко
    emoji: "👋",                 // иконка на урока
    color: "#FF8A65",            // основен цвят на урока (светъл, наситен)
    goal: "Поздравяваш и благодариш учтиво.",  // какво ще можеш след урока (1 изречение, БГ)

    words: [                     // ТОЧНО 10 думи/фрази
      {
        en: "thank you",         // английски, малки букви (освен собствени имена и "I")
        bg: "благодаря",         // превод на български
        emoji: "🙏",             // ЕДНО емоджи, което най-добре илюстрира думата
        ex: "Thank you very much!",        // кратко пример-изречение (3–7 думи), A1 ниво
        exBg: "Много благодаря!",          // превод на примера
        alt: ["thanks"],         // (по желание) други приети английски отговори при писане
        tip: "Звучи като „сенк ю“ – th се казва с език между зъбите."  // (по желание) кратък съвет на БГ
      }
    ],

    grammar: {
      title: "Глаголът to be (съм)",
      explain: "Кратко обяснение на БГ, 2–4 изречения. Може <b>удебелено</b>.",
      table: [["I", "am", "аз съм"], ["you", "are", "ти си"]],  // (по желание) кратка таблица до 6 реда
      examples: [                // 3 примера, оцветени по части
        { parts: [["I","s"],["am","v"],["from Bulgaria","o"]], bg: "Аз съм от България." }
      ]
    },

    reading: {
      title: "В самолета",       // заглавие на БГ
      text: [                    // 4–6 кратки изречения, ползват думи от този и предишни уроци
        { en: "Hello! My name is Anna.", bg: "Здравей! Казвам се Анна." }
      ],
      questions: [               // ТОЧНО 3 въпроса на БГ; options на БГ; answer = индекс на верния
        { q: "Как се казва жената?", options: ["Анна", "Мария", "Елена"], answer: 0 }
      ]
    },

    phrases: [                   // ТОЧНО 3 полезни изречения за пътуване/ежедневие с думите от урока
      { en: "Excuse me, where is the hotel?", bg: "Извинете, къде е хотелът?" }
    ]
  }
];
```

## Цветове на частите в `grammar.examples[].parts`
- `"s"` – подлог (кой?) → синьо
- `"v"` – глагол / сказуемо → зелено
- `"o"` – останалото (допълнение, обстоятелство) → оранжево
- `"k"` – ключовата граматична част, която урокът учи (напр. „-s“, „don't“, „a/an“) → розово
- `""` – без оцветяване

## Правила
- Ниво A1 (към A2 в последните уроци). Кратко, просто, естествено, американско/британско – неутрално.
- Изреченията в примери, четене и фрази да ползват предимно думи от текущия и предишните уроци.
- Без повтаряне на `en` думи между уроците.
- Всичко обяснително – на правилен български. Без транслитерации, освен в `tip`.
- Пунктуацията в `ex`, `phrases`, `reading` – нормална (главна буква, точка/въпросителна).
- Валиден JavaScript (ES модул). Двойни кавички за низовете. Внимавай с апострофите вътре в низовете (I'm, don't) – те са ОК в двойни кавички.
