# Ръчни потвърждения

`confirmations.csv` – попълва се след обаждане или проверка на място. Всеки ред потвърждава
един факт за един обект и прави етапа или връзката **потвърдени** в отчета.

| колона | значение |
|---|---|
| obekt | идентификатор на разрешението (hash от регистъра) или „номер\|район“, напр. `123/28.08.2026\|Подуяне` |
| pole | `етап`, `архитект`, `строител`, `проект`, `доказателство`, `събитие`, `контакт инвеститор`, `изключен източник` |
| stoinost | стойността: етап, име на фирма, име на проект, описание на документа/събитието, „телефон; имейл; сайт“ |
| status | празно = потвърдено; `кандидат` = за преглед (не се приема за потвърдено) |
| eik | ЕИК на участника (по избор) |
| iztochnik | откъде е информацията (сайт, документ, обаждане) |
| url | линк към източника |
| publikuvano | дата на публикуване на източника, ГГГГ-ММ-ДД (празно, ако не е посочена) |
| provereno | дата на проверката, ГГГГ-ММ-ДД (старата колона `data` се чете като тази) |
| belezhka | основание / допълнение |

`събитие` е историческо (напр. „излети основи“ по новина на строителя) и не променя етапа.
`изключен източник` маха връзките, намерени на страница за друг проект.
Ръчните данни само допълват записа – не презаписват потвърдено от регистрите.
